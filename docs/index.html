Vouches, prices & tickets
for one DonutSMP trader

A Discord bot for numbered vouch cards, a live Skeleton spawner price panel, buy/sell tickets and schematic posting.

🧾 Vouch cardsSpawner, build and giveaway vouches with proof, auto-numbered.
💰 Price panelLive buy/sell prices with buttons. Shown as (16.2m) 16,200,000.
🎫 TicketsIGN and amount form, total at current rate, claim and close.
📊 SummaryLive stats panel that refreshes after every vouch.
🏗️ SchematicsSend pictures and a file, get one post with build number and creator.
🔢 Renumbering/vouchremove fixes later vouch numbers in place.

Commands

Only /spawnerbuy and /spawnersell are for everyone. All others are owner-only.

/spawnerpriceSet buy/sell price and update the panel
/spawnerbuy /spawnersellPrice calculators (anyone)
/spawnervouchSpawner vouch: trade, value, amount, vouch, proof
/buildvouchBuild vouch, optional .litematic
/giveawayvouchGiveaway vouch with proof of payment
/vouchremove /vouchfixRemove a vouch and renumber, or re-sync numbers
/summaryPost the live summary panel
/ticketpanel /close /ticketSupport panel and ticket controls
/schematicchannel /boosterchanneladd / remove / list schematic channels with a prefix
/schematiceditChange name, creator, number or size of a post
/purgeBulk delete with confirmation

Schematic posting

  1. /schematicchannel add a channel with a prefix like B.
  2. Send ONE message with the pictures and the file. First line = build name.
  3. The bot posts it with BUILD NUMBER: B1, size and creator, then deletes yours. @mention to credit someone else.
Needs Message Content Intent (Developer Portal) and MESSAGE_CONTENT_INTENT=true. Bot needs Send Messages, Attach Files, Manage Messages there.

Setup

npm install
cp .env.example .env   # fill it in
npm start

Node 18.17+. Invite with permissions=257040 and scopes bot applications.commands. Keep data/ when updating. On a panel host, startup file is src/index.js.

.env

Required: DISCORD_TOKEN, VOUCH_TARGET_ID, ALL_VOUCHES_CHANNEL_ID.
Optional: GUILD_ID, SPAWNER_VOUCHES_CHANNEL_ID, BUILD_VOUCHES_CHANNEL_ID, GIVEAWAY_VOUCHES_CHANNEL_ID, COMMAND_ROLE_ID, TICKET_CATEGORY_ID, OWNER_IGN, MESSAGE_CONTENT_INTENT, SCHEMATIC_BRAND.
